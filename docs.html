The Dryhole Network

Dryhole is an NFT-driven ecosystem built around two generations of NFTs, mining, Genesis progression, and a native token economy.

The ecosystem consists of:

V1  DRYHOLE V1 V2  DRYHOLE V2 / Genesis

Each generation has different utilities within the ecosystem.

01

NFTs

DRYHOLE V1

V1 is the original Dryhole NFT collection.

V1 NFTs can be used for:

  • Drill
  • Burn

V1 remains part of the Dryhole ecosystem after the launch of V2.

V1 holders also receive access to the Genesis ecosystem according to the Genesis holder allocation.

DRYHOLE V2 — Genesis

V2 is the Genesis NFT collection.

V2 NFTs can be used for:

  • Genesis
  • Drill

Genesis introduces a Generation system based on the number of NFTs used.

Higher Generations provide higher Point multipliers.

02

Genesis

Genesis is the core progression system of Dryhole.

Users must meet the required number of NFTs to access each Generation.

GenerationNFT Requirement
GEN 15 NFTs
GEN 210 NFTs
GEN 320 NFTs
GEN 430 NFTs
GEN 550 NFTs

The requirement must be fully satisfied.

Example

A user owns 40 NFTs.

If they select GEN 4:

  • 30 NFTs are allocated to Genesis
  • The remaining 10 NFTs are still available
  • The remaining NFTs can be used for Drill
30 · GENESIS
10 · DRILL

NFTs allocated to Genesis cannot simultaneously be used for Drill.

04

Points

Genesis generates Points based on the selected Generation.

Points accumulate during the active Epoch.

Points are used to determine a user's share of the Epoch reward pool.

Points are not a permanent balance that accumulates forever.

05

Epoch

Dryhole operates using Epoch-based rewards.

Each Epoch ends at23:00 UTC

At the end of each Epoch

  1. The total Points across participants are calculated.
  2. The reward pool is distributed according to each participant's share of the total Points.
  3. The Epoch resets.
  4. A new Epoch begins.
Example
UserPointsShareReward
User A1,00025%25% of pool
User B3,00075%75% of pool
Total4,000100%—

User A owns 25% of the total Points. User B owns 75% of the total Points. The reward pool is distributed accordingly.

06

Drill

Drill is a separate NFT utility.

Both V1 and V2 NFTs can be used for Drill.

  • V1 → Drill
  • V2 → Drill

NFTs being used in Genesis cannot simultaneously be used for Drill.

Example

A user owns 40 NFTs and selects GEN 4. GEN 4 requires 30 NFTs.

  • 30 NFTs → Genesis
  • 10 NFTs → Available for Drill

Users can decide how to allocate their NFTs between Genesis and Drill.

07

Burn

Burn is exclusively for DRYHOLE V1.

V1 holders can permanently burn their V1 NFTs through the Burn system.

Burned NFTs cannot be recovered.

V2 NFTs are not part of the V1 Burn system.

08

Native Token

Dryhole has its own native token.

The native token is the primary currency of the Dryhole ecosystem.

Dryhole's internal Market uses the native token rather than ETH or USDG as its primary trading currency.

The native token connects the NFT economy with the rest of the Dryhole ecosystem.

09

Swap

The Swap page contains three main actions.

ActionDescription
BUYBuy the Dryhole native token through the supported swap route.
SELLSell the Dryhole native token through the supported swap route.
CONVERTConvert eligible Genesis rewards / Points into the Dryhole native token according to the active protocol rules.
10

Market

The Market allows users to trade Dryhole NFTs.

Supported NFTs:

  • DRYHOLE V1
  • DRYHOLE V2 / Genesis

Users can:

  • Buy V1
  • Sell V1
  • Buy V2
  • Sell V2

The Market uses the Dryhole native token as its primary currency, not ETH or USDG.
